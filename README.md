# QQ喵喵助手

一个基于无障碍服务实现的 QQ 输入文本趣味改写工具：在你打字时自动把文本改写成"喵系"风格，比如追加"喵"、句末加颜文字、自定义词语替换。

## 功能特性

- **断句追加**：在句号、感叹号等标点分句后自动追加文本（默认"喵"，可自定义）
- **句末颜文字**：在消息末尾附加随机颜文字，内置 50+ 猫猫颜文字库，也支持自定义
- **文本替换规则**：每行一条 `原词=替换词`，按顺序应用（例：`我=本喵`）
- **两种处理模式**：
  - 标点触发（推荐）：只在输入标点时处理一次，干扰最小
  - 实时处理：每输入一个字即处理
- **控制面板**：所有规则均可在 App 内可视化配置，附带"测试当前配置"实时预览

## 工作原理

通过 Android 无障碍服务监听 QQ（`com.tencent.mobileqq`）输入框的文本变化，对输入框内容做本地文本替换后写回。服务仅在 QQ 界面内生效，不干预其他应用。

## 隐私声明

- **无网络权限**：`AndroidManifest.xml` 中未声明 `INTERNET` 权限，代码中也不存在任何网络请求。欢迎自行审计源码验证。
- **全本地处理**：文本改写、配置存储（SharedPreferences）全部在设备本地完成，不上传、不收集任何用户数据。
- **开源可验证**：全部源码公开，任何"窃取数据"的说法都可以通过代码证伪。

## 权限说明

本应用需要开启**无障碍服务**权限，这是读取并改写输入框文本的唯一系统级途径。Android 系统会将无障碍权限提示为"高风险"，这是系统对所有同类应用（输入法、自动化工具等）的统一提示，属正常现象。是否授权完全由你决定。

## 使用方法

1. 安装 APK（或自行构建，见下）
2. 打开 App，点击"前往开启无障碍服务"，在系统设置中找到"QQ喵喵助手"并开启
3. 在控制面板中配置追加文本、颜文字、替换规则，点击"保存设置"
4. 打开 QQ 任意聊天窗口开始打字，文本会被自动改写

> 注意：QQ 版本更新可能导致输入框控件 ID 变化，若某天突然失效，通常是这个原因，欢迎提 Issue。

## 从源码构建

```bash
git clone https://github.com/xinian5216/QQMiaoAssistant.git
cd QQMiaoAssistant
./gradlew assembleDebug
# 产物位于 app/build/outputs/apk/debug/
```

要求：JDK 17、Android SDK（compileSdk 34）。工程无第三方依赖，仅使用原生 Android 框架 API。
